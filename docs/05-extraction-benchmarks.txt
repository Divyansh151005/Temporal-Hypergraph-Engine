1. ARCHITECTURAL OVERVIEW
--------------------------------------------------------------------------------

An in-memory hypergraph is useless if the initial Knowledge Extraction pipeline (LLM parsing text -> Graph Operations) hallucinates or drops information. 

This module provides an automated evaluation harness to continuously measure extraction quality. It relies on three phases:
1. Synthetic Generation: Creating gold-standard (Ground Truth) datasets containing raw text and their exact hypergraph representations.
2. Extraction Pipeline: Running the target LLM over the raw text to generate a predicted hypergraph.
3. Graph Alignment & F1 Scoring: Comparing the Predicted Graph against the Ground Truth Graph using Bipartite Graph Isomorphism algorithms.

--------------------------------------------------------------------------------
2. SYNTHETIC DATA GENERATION PIPELINE
--------------------------------------------------------------------------------

To avoid human annotation bottlenecks, we generate multi-hop temporal logic puzzles and corporate relationship timelines synthetically using a frontier LLM (e.g., GPT-4o), operating in "reverse".

2.1 The "Reverse Generation" Protocol
Instead of asking an LLM to extract a graph from text, we:
1. Programmatically generate a strictly valid JSON Ground Truth Hypergraph (nodes, temporal edges).
2. Prompt the LLM to write a complex, unstructured news article, transcript, or narrative that perfectly describes the generated JSON graph.
3. Save the pair (`article.txt`, `ground_truth.json`).

3. GRAPH ALIGNMENT & F1 SCORING METRICS

---

Evaluating graph extraction requires partial matching. A predicted edge might have the correct participants but the wrong timestamp.

3.1 Bipartite Node Alignment (Entity Resolution)
Before scoring edges, we must align predicted nodes with ground-truth nodes.

* Use Cosine Similarity on Node Labels.
* Threshold: If `cosine(predicted_label, truth_label) > 0.90`, treat as a match.

3.2 Edge Scoring Logic
For each predicted hyperedge matched to a ground-truth hyperedge:

1. Semantic Match (0.0 to 1.0): Matches `event_type`.
2. Participant Jaccard Index (0.0 to 1.0): `Intersection(Pred_Nodes, Truth_Nodes) / Union(Pred_Nodes, Truth_Nodes)`.
3. Temporal Boundary IoU (0.0 to 1.0): Intersection over Union of the time spans `[valid_from, valid_to]`.

Overall Edge Score = (Semantic * 0.3) + (Participant * 0.5) + (Temporal * 0.2).
Threshold for True Positive (TP): Edge Score > 0.80.

3.3 Standard Metrics

* Precision = TP / (TP + FP)  -> (How much of what we extracted was correct?)
* Recall = TP / (TP + FN)     -> (How much of the truth did we successfully extract?)
* F1 Score = 2 * (Precision * Recall) / (Precision + Recall)

def calculate_jaccard(list1: List[str], list2: List[str]) -> float:
    set1, set2 = set(list1), set(list2)
